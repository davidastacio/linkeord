# Linkeo

Base inicial de Linkeo, una plataforma para emprendedores que venden productos sin inventario.

## Stack

- Next.js App Router
- TypeScript
- TailwindCSS
- Componentes estilo shadcn/ui
- lucide-react
- Framer Motion
- Recharts

## Rutas

- `/` landing page
- `/dashboard` dashboard del emprendedor
- `/admin` panel administrativo
- `/login` acceso demo sin autenticacion real

## Uso

```bash
pnpm install
pnpm dev
```

Para validar produccion:

```bash
pnpm build
```
